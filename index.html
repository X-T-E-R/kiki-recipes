四种接入通道对比

    KIKI RECIPE SOURCE READER PROTOCOL
  


  

    

      
CHANNEL 01 · FOLLOW

      
Latest 浮动分支直连

      

        指向 recipes/<id>/recipe.toml。导入 Kiki 后默认设为 update_mode = "follow"，每 24 小时检查一次更新，适合日常主力环境跟随演进。
      

    

    

      
CHANNEL 02 · VERSION SNAPSHOT

      
Version 版本目录冻结

      

        指向 versions/<id>/<ver>/recipe.toml。构建脚本强制校验已发版本字节不可变，无需填写 SHA-256 即可永久锁死该版本内容。
      

    

    

      
CHANNEL 03 · GIT TAG

      
Git Tag 不可变引用

      

        指向 <id>-v<ver> 标签下的清单文件。依托 Git 标签锁定历史快照，适合在团队文档或评测基线中跨版本引用。
      

    

    

      
CHANNEL 04 · DETERMINISTIC ZIP

      
ZIP + SHA-256 硬锁定

      

        指向 releases/<id>-<ver>.zip 并附 64 位校验和。Kiki 检测到 sha256 后自动将安装设为 pinned，杜绝任何远端漂移。
      

    

  


  

    构建与防呆校验：修改 recipes/<id>/ 并升 version 后执行 node scripts/build.mjs
